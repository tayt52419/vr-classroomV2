# 🏫 ห้องเรียนเสมือนจริง 3 มิติ (VR Classroom)

เว็บไซต์ห้องเรียน 3 มิติ เดินสำรวจได้ด้วยเมาส์และคีย์บอร์ด ทำด้วย HTML + JavaScript + Three.js (r128)
ไม่ต้องติดตั้งหรือ build ใด ๆ เป็นเว็บแบบ static ไฟล์เดียว

## ฟีเจอร์
- ห้องเรียน 3 มิติ Low-poly (เบา เหมาะกับคอมสเปกต่ำ)
- ตัวละครของผู้เล่น (นักเรียน) มองได้ทั้งมุมบุคคลที่ 1 และที่ 3
- คุณครู (NPC) เดินตรวจรอบห้องและเขียนกระดาน
- คลิกวัตถุเพื่อดูข้อมูล / มีป้ายแนะนำอุปกรณ์ (ซ่อน–แสดงได้)
- นั่งเก้าอี้ กระโดด วิ่ง โบกมือ เต้น ยกมือ
- เปิด–ปิดไฟ, กลางวัน–กลางคืน, ประตูเปิดได้, โปรเจกเตอร์ฉายสไลด์, นาฬิกาเดินตามเวลาจริง

| การกระทำ | วิธี |

## เปิดใช้งานบนเครื่อง
ดับเบิลคลิก `index.html` (ต้องต่อเน็ต เพราะโหลด Three.js จาก CDN)
หรือรันเซิร์ฟเวอร์: `npx serve .`

## อัปโหลดขึ้น GitHub
1. สมัคร/เข้าสู่ระบบ https://github.com
2. กด **New repository** ตั้งชื่อ เช่น `vr-classroom` แล้วกด **Create repository**
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง จากนั้นกด **Commit changes**

หรือใช้คำสั่ง (ต้องติดตั้ง Git):
```
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้/vr-classroom.git
git push -u origin main
```

## Deploy บน Vercel
1. เข้า https://vercel.com แล้วเข้าสู่ระบบด้วยบัญชี GitHub
2. กด **Add New… → Project** แล้วเลือก repository `vr-classroom` กด **Import**
3. ตั้งค่า **Framework Preset: Other** (ไม่ต้องใส่ Build Command และ Output Directory)
4. กด **Deploy** รอสักครู่จะได้ลิงก์ `https://ชื่อโปรเจกต์.vercel.app`

ทุกครั้งที่ push โค้ดใหม่ขึ้น GitHub Vercel จะ deploy ให้อัตโนมัติ
